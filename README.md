# Flipkart Customer Behavior Analysis and Market Basket Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior on Flipkart using Python and Machine Learning techniques. The objective is to understand customer preferences, purchasing patterns, satisfaction levels, and recommendation effectiveness to generate actionable business insights.

The project combines Exploratory Data Analysis (EDA), Customer Segmentation, Market Basket Analysis concepts, and Machine Learning to support data-driven decision-making.

---

## Business Problem

E-commerce platforms need to understand customer behavior to:

* Improve personalized recommendations
* Increase customer satisfaction
* Reduce cart abandonment
* Enhance customer retention
* Optimize marketing campaigns
* Improve product recommendation systems

---

## Dataset Information

The dataset contains customer shopping behavior information including:

* Customer Demographics
* Purchase Frequency
* Product Categories
* Browsing Behavior
* Product Search Methods
* Shopping Satisfaction
* Customer Reviews
* Recommendation Helpfulness
* Cart Abandonment Factors

## Project Workflow

### 1. Data Cleaning

* Removed duplicate records
* Handled missing values
* Standardized categorical variables
* Converted rating columns to numeric format

### 2. Exploratory Data Analysis

* Customer demographic analysis
* Purchase frequency analysis
* Product category analysis
* Browsing behavior analysis
* Customer satisfaction analysis

### 3. Customer Segmentation

* Applied K-Means Clustering
* Identified customer groups based on purchasing behavior
* Created customer profiles for targeted marketing

### 4. Recommendation Analysis

* Studied recommendation effectiveness
* Analyzed review engagement patterns
* Evaluated customer trust in recommendations

### 5. Visualization

* Bar Charts
* Pie Charts
* Heatmaps
* Correlation Analysis
* Customer Segmentation Visualizations

## Machine Learning Implementation

### K-Means Clustering

The K-Means Clustering algorithm was used to group customers with similar purchasing patterns and satisfaction levels.

Customer Segments:

* Frequent Buyers
* Occasional Shoppers
* At-Risk Customers
